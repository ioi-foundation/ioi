Usage rules

Proportions. Mark height is 2.65× the wordmark block height. Gap between mark and wordmark is 7.5% of the mark's width. Inside the block: DECENTRALIZED cap 22.072, CLOUD cap 38, 7.116 between the lines; the dot 7.6 square, radius a quarter of its side, on the baseline. Never restyle these relationships.
Clear space. Keep a margin of one node-square (the network node size at the used scale) × 4 on all sides of the lockup.
Minimum sizes. Full lockup: 200px wide (block 24px). Mark alone: 48px wide. Below that, use the reduction glyph; below 32px expect the glyph's network to close.
Colour discipline. Only the palette above. No added hues, no brighter cyan, no glow, blur or drop shadow on the flat marks. Mono variants for single-colour contexts (engraving, print, embroidery). Cyan is a mark colour, not a text colour on light grounds.
The dot. The dot before CLOUD is a fixed brand device — it always carries the cloud gradient, never plain white or black, even in the mono lockups' wordmark.
The wordmark. Set only in IOI Display, two lines, DECENTRALIZED over CLOUD with CLOUD tracked so every letter gap equals the dot's gap. Never re-set it in another face, never one line, never animate it. Drawn letters are not permitted (owner ruling, 2026-09-05).
The gradient. One ramp across the whole cloud, bottom-left indigo to top-right cyan. Never per-shape, never reversed.
Motion. The hover cloud above is the hero treatment for web, and the animated SVG mark is the lockup the site header carries. Static lockups everywhere else. Never animate the wordmark. Every animation stops under reduced motion.
