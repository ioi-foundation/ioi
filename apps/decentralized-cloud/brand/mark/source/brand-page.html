Usage rules

Proportions. Mark height is 2.65× the wordmark block height. Gap between mark and wordmark is 7.5% of the mark's width. Never restyle these relationships.
Clear space. Keep a margin of one node-square (the network node size at the used scale) × 4 on all sides of the lockup.
Minimum sizes. Full lockup: 200px wide. Mark alone: 48px. Below that, use the reduction glyph.
Color discipline. Only palette colors above. No added hues, no brighter cyan, no glow or blur effects. Mono variants for single-color contexts (engraving, print, embroidery).
The dot. The gradient dot before CLOUD is a fixed brand device — it always carries the cloud gradient, never plain white.
Motion. The animated mark is the hero treatment for web. Static lockups everywhere else. Never animate the wordmark.
