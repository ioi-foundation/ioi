Icon — the expiring dot
The dot is the price. The open ring is how long it is good for, and the gap is that it expires. Below 24px the ring is dropped, not thinned — a hairline that vanishes on a tab is worse than an honest solid dot.

Dot geometry
Diameter is 0.205 of the cap height, sitting on the baseline where a period would. IOI Display carries no period glyph, so the one mark the face cannot set is the one we draw.
Clear space
One cap height on every side of the lockup, measured from the outermost ink. Nothing sits inside it, including the IOI endorsement line.
Minimum size
Horizontal lockup down to 132px wide; below that the stacked lockup; below 96px the icon alone. Never set the wordmark in anything but IOI Display, and never letterspace it past 0.01em.
