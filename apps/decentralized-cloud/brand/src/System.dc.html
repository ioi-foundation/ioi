Each swatch names the token it is, in packages/design-system/tokens/colors.css. Exactly one was added to that file for this product rather than kept on a sheet: green-on-dark, because link green measures 3.53:1 on onyx and fails AA where this measures 8.78:1. A second was drafted and then deleted — a darkened red for the expired chip — once measurement showed red-600 already clears at 4.87:1 and the token was solving nothing. Every figure in this paragraph comes from brand/measure-contrast.mjs, which prints them from the hex values themselves; the first draft of this sheet asserted two contrast numbers from memory and both were wrong.

IOI Display is unicase and carries no digits and no period, so it sets the wordmark and nothing else — never a price, never a timestamp, never a heading with a number in it. The system's fourth face, Martina Plantijn, is the umbrella's editorial serif and is deliberately unused here: a console that reports machine state has no editorial voice to speak in.
Evidence states — the one component this product cannot do without
live_evidence simulated_control_plane advisory_only candidate_source_unavailable expired not wired — job api not live
Green means live, and only live. A candidate wears it when the daemon returned it as evidence_mode: live_evidence, and a source wears it when the daemon reports it answering — live_quote_source, available, storage_backends_engaged. It is never chrome: not the selection colour, not a callout accent, not the current tab. The one green that is not a status is the wordmark's own dot, which is the mark itself.
Grey is absence, red is time. A source with no adapter or no credential is grey and says why, in the daemon's own words, in the row where a price would have been. Red means one thing only: a quote whose expires_at has passed and which the surface has not yet refreshed. A state dot carries meaning, so it is drawn in grey-700 at 3.90:1 rather than a hairline grey that would fail the 3:1 floor for non-text.
Unwired is visible. Write surfaces designed ahead of the kernel carry the last chip and cannot be submitted. A stub a reader cannot tell apart from truth is refused; a labelled one is a design deliverable.

The endorsement sets IOI in the same face at 13px against the lockup's 28px, on one line, outside the clear-space boundary. Brand is not owner: decentralized.cloud proposes candidates, wallet.network authorizes, Hypervisor places and executes, Agentgres records what ran and what it cost. The face composes those four and adds none, and this line is the only place the umbrella appears.
