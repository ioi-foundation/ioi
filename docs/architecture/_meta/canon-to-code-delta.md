## Why this file exists

The estate reached an audited application plane (the operational-depth atlas,
`apps/hypervisor/application-operational-depth.json`) whose remaining queue
ranked SURFACE work. The canon's next leg is not surface work: it begins with
the constitution/deployment/continuity object plane, then the
collaborative-pursuit and federated-ontology object plane. This file records,
object by object, what the canon requires, what the code holds today, and what
crossing turns the delta into durable truth — so application UX resumes only
when an implemented contract pulls it.

Reading rules:

- **Implementation state** is honest: `not started` means the object's
  durable form does not exist in code — even when an adjacent substrate is
  named as an explicitly labeled *implementation precedent* (a precedent is
  never a partial instance). `partial` is reserved for rows where a real
  slice of the object itself persists. Nothing planned is described as
  shipped.
- Contract generations are assessed independently. Retaining a mounted
  predecessor route or record family for historical regression and source
  disposition does not make it an implementation of the current contract, and
  predecessor evidence cannot prove a current-generation claim.
- **Next authority crossing** is the first daemon/Agentgres/wallet boundary the
  object must cross to exist as governed truth (not a UI milestone).
- **Owning application projection** names the product surface that will RENDER
  the object. Projections never own the truth; the daemon/Agentgres contracts
  in the row do.
- **Every cell here is an implementation-state claim and carries its measurement
  basis.** A cell asserting that something does not exist — `not started`,
  `route-missing`, `schema-missing` — names the layers that were searched, or
  scopes itself to the layer it checked. This estate serves through six: daemon
  routes, the serve lane, augmentation modules, the `surfaces/` module
  directories, the RPC adapter, and the product derivative. An unscoped absence
  claim backed by a single-layer search is a defect in this file; a scoped one
  ("not present in the daemon layer; other layers not searched") is complete and
  acceptable. Any count quoted from a frozen artifact carries that artifact's
  commit, its distance from HEAD, and what it excludes.
- **Every citation here resolves in a clone.** No cell may rest on an ignored or
  untracked path as its load-bearing evidence.
